COMO PERSONALIZAR

1. Abra index.html.
2. Troque "SEU NOME" pelo nome artístico.
3. Troque "Artista" pela assinatura/subtítulo.
4. No iframe do YouTube, substitua VIDEO_ID pelo ID do seu vídeo.
   Exemplo: https://www.youtube.com/watch?v=ABC123 -> ABC123
5. Substitua cada href="#" pelos links reais das plataformas.
6. Coloque a sua capa na pasta com o nome release-cover.jpg.
7. Altere o email contacto@seudominio.com.
8. Para alterar as redes sociais, edite os href="#" da seção de redes.

AUTOPLAY
O vídeo está configurado com autoplay + mute. Os navegadores normalmente permitem autoplay sem som, mas podem impedir autoplay com áudio.

PUBLICAÇÃO
A página é estática e pode ser publicada em Vercel, Netlify ou GitHub Pages. Depois pode receber um domínio próprio.
